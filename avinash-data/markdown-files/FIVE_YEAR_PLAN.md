# 5-Year Financial Survival Plan
## From 1 Pilot School → 10 Paying Schools (April 2026 – March 2031)

> **Strategy:** India's academic year runs April → March. Schools ONLY adopt new software
> at the start of a new academic year. This plan is built around that reality.
> Annual fees collected **upfront in April** — this is the cashflow lifeline.

---

## Key Assumptions

| Assumption | Value | Reasoning |
|---|---|---|
| Average school size | 500 students | Mid-range private school |
| Academic year | April 1 → March 31 | CBSE/standard India |
| New school adoption window | **April only** | Schools don't change tools mid-year |
| Payment model | **Annual, paid upfront in April** | Best cashflow; schools budget annually |
| Bootstrap capital needed | **₹10,00,000 (₹10 lakh)** | Personal savings / family loan |
| USD to INR | ₹84 | Fixed for this plan |
| Student count per school | 500 (constant) | Consistent for modelling |
