## Purpose

Customer Onboarding covers everything required to prepare a **signed school** for pilot:

- Dedicated tenant creation
- Real curriculum and operational data import
- Staff account provisioning
- Training and handover

Customer Pilot **does not begin** until onboarding is complete. See [`customer-pilot/README.md`](../customer-pilot/README.md).
