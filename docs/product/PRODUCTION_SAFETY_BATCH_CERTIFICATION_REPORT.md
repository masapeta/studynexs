## 5. Independent review corrections

Independent review initially returned NO-GO for two findings:

1. expense input still entered as `float`;
2. CORS accepted unspecified addresses and unusable origin spellings.

Both were corrected before this report:

- `SchoolExpenseCreate.amount` is now constrained `Decimal`, with exact
  `0.10 + 0.20 == 0.30` and excessive-precision rejection tests;
- production CORS now rejects `0.0.0.0`, `[::]`, surrounding whitespace,
  trailing slash, credentials, path/query/fragment, and malformed ports.

The review also identified synchronous WeasyPrint execution as an event-loop
risk. PDF work is now dispatched through `run_in_threadpool` at the async
request boundaries.
