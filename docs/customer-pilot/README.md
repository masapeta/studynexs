# Customer Pilot

> **Prerequisites:** Contract signed · dedicated tenant created · customer curriculum imported · teachers trained  
> **Not started until onboarding completes**

---

## Purpose

Customer Pilot is **real-world validation** on a signed school's **own data** — bounded wedge (typically one class × subject), with HOD and teacher feedback.

This is **separate** from the [Showcase (Reference School)](../showcase/README.md), which uses representative sample data for sales demonstrations.

See [`customer-journey/README.md`](../customer-journey/README.md).
